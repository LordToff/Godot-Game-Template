# Download Ash & Oath v0.5 for Windows

[**Download Windows v0.5 (ZIP)**](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/downloads/AshAndOath-Windows-v0.5.zip)

1. Download the ZIP above. Sign in to GitHub if asked.
2. Right-click the ZIP → **Extract All**. Use a **new folder** to avoid mixing old files.
3. Open the extracted folder and run **AshAndOath.exe**. No Godot installation needed.
4. Each hero chooses **two distinct faces** from the complete **47-face extended pool**. Starter faces are excluded. Search/filter, select two and confirm, then customize the legal auto-build if desired.

New: easy topic-based patch notes, turn explanations, **two Blanks minimum per die**, **Ashstep / Oathbound Exchange**, **View dice** with live mutation tracking, and a varied boss with pulls, Block theft and a delayed marked explosion. Tuned boss HP is 16; Original encounter mode remains available.

The extracted `VERSION.txt` should say **0.5.0**. Windows was cross-exported with Godot 4.6.3; Linux and browser builds were run in development. Extended abilities use explicitly printed prototype variants.
