# Download Ash & Oath v0.3 for Windows

[**Download Windows v0.3 (ZIP)**](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/downloads/AshAndOath-Windows-v0.3.zip)

1. Download the ZIP above. Sign in to GitHub if asked.
2. Right-click the ZIP → **Extract All**. Use a **new folder** to avoid mixing old files.
3. Open the extracted folder and run **AshAndOath.exe**. No Godot installation needed.
4. Each hero chooses **two distinct faces** from the complete **45-face extended pool**. Starter faces are excluded. Search/filter, select two and confirm, then customize the legal auto-build if desired.

New: attack/block/buff/debuff animations, a ruined-courtyard backdrop, a structured readable battle chronicle with filters/copy, and balance/reliability corrections. One starting reroll per hero and original/tuned encounter options remain.

The extracted `VERSION.txt` should say **0.3.0**. Windows was cross-exported with Godot 4.6.3; Linux and browser builds were run in development. Extended abilities use explicitly printed prototype variants.
