# Download Ash & Oath v0.4 for Windows

[**Download Windows v0.4 (ZIP)**](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/downloads/AshAndOath-Windows-v0.4.zip)

1. Download the ZIP above. Sign in to GitHub if asked.
2. Right-click the ZIP → **Extract All**. Use a **new folder** to avoid mixing old files.
3. Open the extracted folder and run **AshAndOath.exe**. No Godot installation needed.
4. Each hero chooses **two distinct faces** from the complete **45-face extended pool**. Starter faces are excluded. Search/filter, select two and confirm, then customize the legal auto-build if desired.

New: tall side chronicle, clear active-turn banner, smoother animations, **Tutorial / Ability Lab** for every face, ability fixes, Numeric attack balancing and **What changed** in-game with reasons. Start the Lab directly from the opening picker to test without drafting.

The extracted `VERSION.txt` should say **0.4.0**. Windows was cross-exported with Godot 4.6.3; Linux and browser builds were run in development. Extended abilities use explicitly printed prototype variants.
