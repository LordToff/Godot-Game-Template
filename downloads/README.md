# Download Ash & Oath v0.8 for Windows

[**Download Windows v0.8 (ZIP)**](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/downloads/AshAndOath-Windows-v0.8.zip)

1. Download the ZIP above. Sign in to GitHub if asked.
2. Right-click the ZIP → **Extract All**. Use a **new folder** to avoid mixing old files.
3. Open the extracted folder and run **AshAndOath.exe**. No Godot installation needed.
4. Each hero chooses **two distinct faces** from the complete **47-face extended pool**. Starter faces are excluded. Search/filter, select two and confirm, then customize the legal auto-build if desired.

New in v0.8: real **3D dice** settling on actual ability faces, persistent **Channel auras**, eight guided practice lessons, Save / Load build presets, Lab ability combinations, clearer target feedback and combat interaction fixes. Fast / Skip keeps rolls unchanged. [Read the six-page guide](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/docs/AshAndOath-Plain-Language-Guide-v0.8.pdf).

The extracted `VERSION.txt` should say **0.8.0**. Windows was cross-exported with Godot 4.6.3; Linux and browser builds were run in development. Extended abilities use explicitly printed prototype variants.
