# Download Ash & Oath v0.7 for Windows

[**Download Windows v0.7 (ZIP)**](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/downloads/AshAndOath-Windows-v0.7.zip)

1. Download the ZIP above. Sign in to GitHub if asked.
2. Right-click the ZIP → **Extract All**. Use a **new folder** to avoid mixing old files.
3. Open the extracted folder and run **AshAndOath.exe**. No Godot installation needed.
4. Each hero chooses **two distinct faces** from the complete **47-face extended pool**. Starter faces are excluded. Search/filter, select two and confirm, then customize the legal auto-build if desired.

New in v0.7: fixes for Downed effect cleanup, lethal Channel break consequences and silent Channel replacement. [Read the clear five-page guide](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/docs/AshAndOath-Plain-Language-Guide-v0.7.pdf). The first reward Soul allows **one Blank-to-Move-2 conversion per hero turn**, refreshed on normal and full recovery turns. [Download the full Word comparison against the base rules](https://github.com/LordToff/Godot-Game-Template/raw/refs/heads/ash-and-oath-prototype/docs/AshAndOath-Changes-From-Base-Rules-v0.6.docx). Previous two-Blank builds, new movement, boss mechanics and reference screens remain.

The extracted `VERSION.txt` should say **0.7.0**. Windows was cross-exported with Godot 4.6.3; Linux and browser builds were run in development. Extended abilities use explicitly printed prototype variants.
