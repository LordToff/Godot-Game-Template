# Ash & Oath v0.23

[Play in your browser](https://lordtoff.github.io/Godot-Game-Template/?v=0.23)

An original three-part soundtrack follows preparation, combat and phase II. Music starts with your first click. Open **Audio** in the footer for separate music/effects levels and mute; your mix is saved on this device. [About the original score](SOUNDTRACK.md).

The polished interface adds pixel chamber framing, serif headings, clearer face cards, consistent panels/menus/workshop, visible keyboard focus, stronger primary controls and readable scrolling patch topics. Hover details and drag placement remain. All four bosses and Summon/Command Nu’gh remain available; combat values and RNG are unchanged.

29 regression scripts passed, plus final presentation and compact-dialog checks. The actual browser export was checked in Chromium/WebGL, with Web Audio output measured for playback, zero volume, restored volume and mute. Bu’gh remains provisionally balanced. The older Windows build is unchanged.
